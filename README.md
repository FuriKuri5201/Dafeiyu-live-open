# 🐟 鲶鱼大帝之大肥鱼一键开播助手

开箱即用的开源 AI 直播一键开播桌面程序：无需懂代码、不用敲命令，打开独立桌面窗口填好 API Key 与房间号，点一下即可开播。

> **设计理念**：只保留纯净、通用的直播基础功能，不包含任何个人数据或私有资产；支持自由切换任意 OpenAI 兼容大模型与 TTS 引擎，每个功能模块均可独立开关，方便小白直接开播，也方便开发者二次魔改。

---

## ✨ 六大核心功能

1. **💬 抖音 / B站 网页版弹幕与礼物采集**
   - 通过 Playwright 启动独立浏览器打开网页版直播间，自动截获页面 WebSocket 推流解析弹幕、礼物、进场与点赞。
   - 自动探测本机 Chrome 或 Windows 自带的 Microsoft Edge，无需额外下载几百 MB 的浏览器内核。
2. **🎁 实时礼物统计与语音答谢**
   - 自动统计本场礼物与贡献榜并同步推送到 OBS 礼物板，支持固定模板答谢或交给大模型自由生成答谢语。
3. **🎙️ AI 语音聊天（自由模型 + 免费 TTS 兜底）**
   - **对话模型**：支持 DeepSeek、通义千问、OpenAI、Ollama 本地模型等所有 OpenAI 兼容接口，内置一键预设。
   - **语音合成**：默认自带**免费免 Key 的 `edge-tts`**（零成本即可开口测试），同时支持阿里云百炼 CosyVoice、OpenAI 兼容 TTS、Windows 本地离线 SAPI。
4. **🎵 本地曲库点歌**
   - 将 `.mp3` / `.flac` / `.wav` / `.ogg` / `.m4a` 放入项目 `music/` 文件夹即可。
   - 观众发送「点歌 歌名」自动模糊匹配入队播放，AI 开口说话时自动压低伴奏音量（Ducking），支持「切歌」。
5. **🎨 AI 画室**
   - 支持阿里云百炼通义万相（可一键复用百炼 TTS Key）或任意 OpenAI 兼容文生图接口，观众发送「画 XXX」自动排队作画并推送至 OBS 画板。
6. **🖥️ OBS 透明舞台 & 🐟 VTube Studio 皮套接口**
   - 内置 OBS 透明浏览器源：弹幕板、主播实时字幕、礼物榜、点歌单、AI 画室。
   - 内置标准 **VTube Studio Public API** 接口（默认端口 `8001`），AI 说话时自动驱动 `MouthOpen` 口型；同时本地 WebSocket 广播 `avatar_state` 事件，方便各类外部皮套或桌宠接入。

## 🚀 快速开始（Windows）

### 方式一：双击一键启动（推荐）

1. 确保电脑已安装 **Python 3.10 ~ 3.13**（安装时勾选 `Add python.exe to PATH`）。
2. 直接双击项目根目录的 **`一键启动.bat`**。
   - 首次运行会自动创建 `.venv` 虚拟环境并安装所需依赖；
   - 安装完成后自动弹出独立桌面控制台窗口。
3. 在首页填好 **API Key** 与 **直播间房间号**，点击右上角或底部的 **「🚀 一键开播」** 即可。

### 方式二：命令行启动（开发者）

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python app.py
```

无界面模式（仅启动本地后端服务）：

```powershell
.\.venv\Scripts\python run_headless.py
```

本仓库**不内置、不二次分发**任何第三方皮套资产，尊重所有画师与模型作者的版权。

如需皮套形象：
- 可直接在 B站搜索「**蓝色大肥鱼开源皮套**」获取原作者分享的免费版本，导入 **VTube Studio**（开启 API 端口 `8001`），再打开本软件首页的「🐟 皮套接口（VTS）」开关即可联动口型；
- 或者直接在直播间挂一个桌宠即可开播。

## 📁 目录结构

```text
dfyzb-open/
├── 一键启动.bat           # Windows 双击无黑框启动桌面控制台
├── start.bat              # 首次初始化虚拟环境与依赖脚本
├── app.py                 # 独立桌面窗口入口（PyWebView）
├── run_headless.py        # 无界面命令行入口
├── config.example.json    # 默认配置模板（首次启动自动生成 config.json）
├── requirements.txt       # Python 精简依赖清单
├── music/                 # 本地曲库目录（放入音乐文件即可点歌）
├── core/                  # 核心引擎（采集 / LLM / TTS / 点歌 / 画室 / VTS / 导演 / 服务）
├── ui/                    # 独立桌面控制台前端界面
└── stage/                 # OBS 透明浏览器源页面（弹幕 / 字幕 / 礼物 / 点歌 / 画室）
```
