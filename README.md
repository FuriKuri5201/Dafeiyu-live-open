# 🐟 鲶鱼大帝之大肥鱼一键开播助手

把 AI 直播最核心的基础功能单独抽出来做成了一个开源一键开播桌面程序——不用写代码、不用敲命令，打开窗口填好 API Key 和房间号，点一下就能直接开播。

- 界面干净直观，每个功能都能单独开关；
- 不绑定固定模型，支持自由切换 DeepSeek、通义千问、OpenAI、Ollama 本地模型等所有 OpenAI 兼容接口；
- 默认自带免费免 Key 的 `edge-tts`，拿到手就能先试播测试。

---

## ✨ 包含的功能

1. **💬 抖音 / B站 网页版弹幕与礼物采集**：启动独立浏览器打开网页版直播间，自动抓取弹幕、礼物、进场和点赞（自动调用本机 Chrome 或 Windows 自带的 Edge，无需额外下载浏览器）。
2. **🎁 礼物统计与语音答谢**：自动统计本场礼物和贡献榜，支持固定模板答谢或让大模型自由回复。
3. **🎙️ AI 语音聊天**：自由配置任意 OpenAI 兼容大模型；TTS 默认免费 `edge-tts`，也可切换阿里云百炼 CosyVoice、OpenAI 兼容 TTS 或 Windows 本地离线语音。
4. **🎵 本地曲库点歌**：把 `.mp3` / `.flac` / `.wav` / `.ogg` / `.m4a` 放进 `music/` 文件夹即可，弹幕发「点歌 歌名」自动播，AI 说话时自动压低伴奏音量，支持「切歌」。
5. **🎨 AI 画室**：支持阿里云通义万相（可直接复用百炼 Key）或 OpenAI 兼容文生图接口，弹幕发「画 XXX」自动排队作画并推到 OBS 画板。
6. **🖥️ OBS 透明舞台 & 🐟 VTube Studio 皮套接口**：内置透明弹幕板、字幕条、礼物榜、点歌单、AI 画室，OBS 加浏览器源就能挂屏；支持连接本地 VTube Studio（默认端口 `8001`）在说话时自动驱动 `MouthOpen` 口型。

## 🚀 怎么使用（Windows）

### 方式一：直接下载免安装绿色版（推荐，不用装 Python）

1. 点页面右侧的 **[Releases](../../releases)**，下载最新版的 `DFYZB-Open-Win64-Portable.zip`。
2. 解压到任意文件夹，双击里面的 **`一键启动.bat`** 就会弹出桌面控制台。
3. 在首页填好 **API Key** 和 **直播间房间号**，点 **「🚀 一键开播」** 即可。

### 方式二：源码运行（适合想自己魔改的开发者）

1. 先安装 **Python 3.10 ~ 3.13**（安装时勾选 `Add python.exe to PATH`）。
2. 下载或克隆本仓库后，直接双击根目录的 **`一键启动.bat`**（首次会自动创建虚拟环境并安装依赖）。

也可以手动在命令行启动：

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python app.py
```

无界面模式（仅启动本地服务）：

```powershell
.\.venv\Scripts\python run_headless.py
```

二次修改后如需自己重新打一份绿色免安装压缩包，直接运行 `.\build_release.ps1` 即可在 `dist/` 下生成便携包（若装了 Inno Setup，也可以编译 `installer.iss` 生成 `Setup.exe`）。

## 🐟 关于直播皮套

本仓库**不内置、不二次分发**任何第三方皮套，尊重画师和模型作者版权。

- 想用皮套的可以直接去 B站搜「**蓝色大肥鱼开源皮套**」，有很多作者免费分享的版本，导入 **VTube Studio**（开启 API 端口 `8001`）后再打开本软件首页的「🐟 皮套接口（VTS）」开关就能联动口型；
- 或者直接在直播间挂个桌宠也能开播。

## 📁 目录说明

```text
Dafeiyu-live-open/
├── 一键启动.bat           # 双击直接打开桌面控制台
├── start.bat              # 源码运行时的首次环境初始化脚本
├── app.py                 # 独立桌面窗口入口（PyWebView）
├── run_headless.py        # 无界面命令行入口
├── config.example.json    # 默认配置模板（首次启动自动生成 config.json）
├── requirements.txt       # Python 依赖清单
├── build_release.ps1      # 绿色免 Python 便携包打包脚本
├── installer.iss          # Inno Setup 安装包脚本模板
├── music/                 # 本地曲库目录（放歌曲文件即可点歌）
├── core/                  # 核心模块（采集 / LLM / TTS / 点歌 / 画室 / VTS / 导演 / 服务）
├── ui/                    # 桌面控制台前端界面
└── stage/                 # OBS 透明浏览器源页面（弹幕 / 字幕 / 礼物 / 点歌 / 画室）
```
